用于记录地区草稿、整理房间与文字设定，并将地图交给 Rained 继续制作。

更新前请导出 RainOC 项目备份。Rained 导出仍为实验性功能；配套模组当前用于区域内测试，暂不负责跨区域切换。

## English

RainocTool helps mod authors record region ideas, organize rooms and lore, and hand maps over to Rained for further editing.

**[Open RainocTool 1.1.2](https://rey544.github.io/rainworld-oc-collection/v1.1.2/)**

The companion rainocmod package includes an importer for bringing rendered room TXT and PNG files into the game. Follow the README included in the package.

Back up your RainOC project before updating. Rained export remains experimental. The companion mod currently supports testing within individual regions, not cross-region transitions.

Thanks to LL77 for map creation, testing, and feedback.
